# FocusClock


## Live Preview

![FocusClock Demo](https://github.com/SSMY444/timer-focus-clock/blob/main/ScreenRecording2026-03-10at11.27.26PM-ezgif.com-optimize.gif)

FocusClock is a colorful desktop focus timer built with Python.
It combines a digital clock, customizable focus sessions, relaxing break timers, and multiple animated themes to create an engaging environment for productivity.

## Features

* Live digital clock
* Custom focus and relax session time
* Automatic focus → break cycle
* Start, Pause, and Reset controls
* Large accessible buttons
* 12 visual themes with colors, shapes, and symbols
* Lightweight single-file Python program
* No external libraries required

## Themes

The application includes multiple visual themes such as:

* Ocean
* Forest
* Sun
* Galaxy
* Dream
* Zen
* Fire
* Ice
* Nature
* Magic
* Love
* Energy

Each theme changes the background visuals and color palette to create a unique atmosphere.

## How It Works

1. Enter the number of minutes for **Focus**.
2. Enter the number of minutes for **Relax**.
3. Press **START** to begin the timer.
4. After the focus session ends, the relax timer starts automatically.
5. Use **THEME** to change the visual style.

## Requirements

* Python 3.x
* Tkinter (included with most Python installations)

No external packages are required.

## Run the Project

Clone the repository and run the script:
